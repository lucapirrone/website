# UX/UI

## Decisions

- **Language:** Italian (`lang="it"`), copy in the concept's tone.
- **Modes:** 3D (default for humans) and Classica; same content. Classic content always present in the HTML.
- **Tokens:** colors and type from the concept (`--ink`, `--panel`, `--f-display`, `--f-mono`).
- **Mobile:** status widget under the brand card; project caption replaced by the in-world sign with CTAs.
- **Accessibility:** WCAG 2.2 AA; `prefers-reduced-motion` disables camera tweens; every 3D action has an HTML equivalent.
